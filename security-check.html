ClassHub Security Check

Tries things that must be refused and shows whether your live Supabase project refuses them. PASS means refused (good). FAIL means it was allowed (a real problem).

This page is for you, not for students. It is not linked from the app. Never run Part 2 with the admin or a CR account, and never with a classmate's PIN.

Part 1: without logging in

What a stranger with only your public key can do. Nothing here changes any data.

With the class code the page also checks that a roll number that is not on your list is refused.

Part 2: as a plain student

What a classmate can do. Use a test student account: sign up in the app with an unused roll from your list, run this, then remove that account from the Students tab.
